# 方法边界

以下为内置方法及其适用条件；根据研究问题、数据结构和方法假设选择。

- **数据**：按指定编码读 CSV/XLSX，不静默修复不明列名、无效值、未知分类和重复患者。完整病例数和缺失数要进入报告；是否可使用完整病例须由研究者判断。
- **基线和检验**：独立双组 Welch t 检验及其差值区间；Mann–Whitney 渐近法、连续性修正；多组普通/Welch 单因素方差分析与 Kruskal–Wallis；无连续性修正 Pearson 卡方，最低期望频数 5；二分类 2×2 双侧 Fisher。成对 t/Wilcoxon 和 Friedman 要求患者间独立。不能把秩和检验一概解释为中位数比较；多组全局检验不自动推断哪些组不同。
- **回归**：仅独立观察的 OLS / 二元 Logistic；数值预测变量及已声明类别、参考组；可按原合同预设固定结点 RCS。Logistic 完全或准完全分离、信息不足、秩缺陷、估计警告或不收敛会阻断。可做预先确定的调整，不自动寻优。源程序的样本和事件数门槛是工程保护，不等于证明样本量合理。
- **生存**：仅正随访时间、明确起点和结局的独立个体右删失 KM / Cox；KM 同时发生事件和删失时先处理事件；Cox 使用 Breslow 处理并列事件。另支持限定 Aalen–Johansen 累积发生率和原因别 Cox；不支持 Fine–Gray。指定正式 PH 检验时按原计算合同运行；未指定时残差趋势不是正式 PH 检验。时间变动、重复事件、聚类和左截断不支持。
- **匹配**：倾向评分来自预先指定的普通 Logistic 模型；确认暴露前协变量、二元组别、完整病例和绝对 logit 卡钳，使用不放回贪心 1:1。平衡采用匹配前 pooled SD 作为前后 SMD 的共同分母。连续结局用配对 t；二分类结局给风险差及双侧精确 McNemar，风险差区间为近似配对 t 区间。未测混杂和配对推断假设需研究复核。
- **预测**：二分类固定 L1 / L2 / Elastic Net Logistic、固定参数随机森林和 HGB；预先指定候选变量、参数与预测时间。独立留出集评估，填补/标准化只在训练集拟合；报告 AUC、Brier、校准及可选预设网格 DCA，不进行阈值搜索、自动调参或外部验证。随机森林保存本机 JSON 树模型并校验分数重放；HGB 不导出冻结模型。模型和研究编号摘要仅存本机。
- **连续结局预测**：固定参数 Ridge、Lasso、Elastic Net；独立个体随机留出验证并输出 RMSE、MAE 和适用的 R²。不自动裁剪不可能的数值；需按结局性质判断模型是否适用。
- **相关、诊断、样本量**：Pearson/Spearman 配对相关；Shapiro 检验；二分类参考标准与指标的灵敏度、特异度及 Wilson 区间；连续评分的 AUC 和按需 bootstrap；均值/比例精度及等组两均值/两比例规划。相关不代表因果，诊断预测值依赖样本患病比例，样本量输入是研究假设。
- **其他限定模型**：独立患者连续纵向随机截距模型；GEE 支持连续或二分类重复结局、独立或可交换工作相关结构、稳健标准误；限定二元暴露、连续中介和结局的线性中介分解；探索性 KMeans/Gaussian mixture。GEE 估计总体平均效应，其独立患者数量和缺失机制需审查。普通纵向混合模型不等于潜类别轨迹；中介分解不证明因果机制；聚类不等于正式 LPA。
- **图表**：基线、回归、KM、匹配和预测输出聚合结果；图件按已算出的数据生成，未提供数据不编造图。中文字体依赖运行机器字体。

当前未实现：Fine–Gray、SHAP、正式潜类别轨迹、分类中介或生存结局中介、复杂抽样、外部模型验证及自动论文撰写。不要把其他 Python 库理论上支持的能力称为本 Skill 已实现。
