# 自动准备本地运行环境

Agent 根据当前电脑和宿主，自行准备并复用本 Skill 的运行环境。文章线优先使用宿主实际提供或可准备的 CPython 3.13；已有经验证兼容的 Python 3.12 环境可继续复用，不为统一而反复安装。必要时按宿主能力、权限及官方来源准备 Python，并按 `requirements.txt` 安装当前缺少的依赖。优先复用兼容的隔离环境；保护原有系统和其他项目的环境。Skill 包不携带 Python 解释器。

环境首次准备、依赖改变或运行异常时，按需运行 `python -m pip check`、`scripts/selfcheck.py` 和 `scripts/clinical.py doctor --method <当前方法>`，自行处理依赖问题后继续；已就绪的环境不必每次重复这些自检。每次仍按当前研究问题检查实际输入、结果和状态，使用实际环境的 Python 执行命令，保留实际版本和分析参数。

不要让医生搜索安装包、挑选依赖或输入命令；需要宿主或系统确认时请医生按提示确认。遇到障碍时先自行处理，确需医生协助时只说明最简单的必要操作。患者记录只在本机处理，不进入安装命令、聊天或外部服务。
