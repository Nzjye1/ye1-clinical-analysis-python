# Ye1 临床分析

**从研究问题和本地数据出发，完成适用的临床统计分析。**

- 支持描述与组间比较、回归、生存、诊断和部分预测等分析，具体以研究问题和数据条件为准。
- 生成可复核的分析结果、表图和说明；数据逐行记录留在本机。
- 分析选择、假设及结果需要研究者和相关专业人员复核。

试着说：“根据我的研究方案和本地数据，分析影响术后并发症的因素。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-clinical-analysis-python-skill.zip)，解压后保留完整的 `ye1-clinical-analysis-python` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-clinical-analysis-python` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-clinical-analysis-python/SKILL.md)。
